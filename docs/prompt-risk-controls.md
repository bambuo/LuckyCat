# 提示词与交易风控调整

本次改动作用于后续生成的提示词与下单流程。历史提示词原文和已保存个性化段落不改写；没有修改运行数据库，也没有重启现有实盘服务。空的个性化段落继续采用代码中的新默认正文。

## 流程设计

| 步骤 | 输入与输出 | 副作用与失败处理 |
|---|---|---|
| 数据准备 | 账户、持仓、候选、行情、平仓历史 → 带时间和完整性的数据 | 读取公开/账户接口；平仓历史按现有同步器增量保存，失败禁止开仓 |
| 提示词生成 | 配置与快照 → 系统/用户提示词及允许开仓标的 | 无交易副作用；持仓行情优先，压缩保留周期和指标预热数据 |
| 决策契约校验 | JSON → 合规动作或拒绝原因 | 不合规输出不执行；保留原始输出供查看 |
| 风险计算 | 决策、新鲜账户、规格、纪律 → OpenTradePlan | TradingRiskPolicy 纯函数，可从此步骤独立起测 |
| 订单提交 | OpenTradePlan → 交易所请求回执 | 通过 IOpenOrderGateway；杠杆失败/持仓模式未知不提交市价单，不自动重发订单 |
| 审计 | 回执 → TraderOrders 与 SSE | 编排层保存现有审计表；成功回执不宣称已核实成交或保护单有效 |

同账户后台交易员在进程内串行检查和提交，提交前重新读取账户、持仓和执行交易所价格。同账户刚提交开仓的十秒内暂停再次开仓以等待交易所同步。此锁不提供多进程分布式互斥。

## 策略和数据规则

- 默认方向周期为已选周期中比主周期更长的最短周期。其他周期补充风险，不要求所有周期一致。新默认配置为 5m/15m/1h；已保存配置不自动改写。
- 默认多头方向：方向周期收盘价 > 快 EMA > 慢 EMA；空头相反。主周期 MACD 柱与方向一致；启用 RSI 时最短参数以 50 为方向阈值。
- 回踩区域为快 EMA ±0.5 ATR；突破确认参考前两根高低点，弱突破距离为 0.25 ATR；三根累计超过 3 ATR 禁止追单。保留止损 1.5 ATR。这些是明确的初始策略参数，未经过收益优化或盈利验证。
- 最近结构目标扣除预算后不满足盈亏比则观望，禁止跳过阻挡来凑目标。不设每日最低交易次数。
- 只用已收盘 K 线确认结构。原始表标注进行中状态；关闭原始 K 线仍提供已收盘结构摘要，成交量开关控制成交量信息。
- OI 分别展示数量和美元名义价值变化、真实窗口与采集时间；Gate 数量为合约张数，Binance 数量按原生字段。只接受相邻一小时窗口。窗口未对齐不能作价格/OI 组合归因。
- 资金费率单次值不证明转负、归零或已结算，也不证明底部。外部新闻与历史理由只作为数据，不接受其中的行为指令。
- 每个开仓目标的必需行情须完整、ticker 可用、采样年龄不超过三分钟、最新已收盘数据未过期且指标可算。无关候选缺失不阻止风险退出。
- 历史记忆按策略与交易员隔离，手工测试独立；完整保存决策 JSON/trigger。注入执行审计回执或明确“未确认”，不把建议当作成交。

## 风控字段

所有百分比字段以百分点表示，`1` 表示 `1%`。`position_pct` 是保证金占账户资金基数的比例；资金基数沿用钱包 USDT 余额，明确不冒充含浮盈亏净值。

新增 `riskControl` 字段可在策略编辑器设置，旧 JSON 缺失时使用以下默认值：

| 字段 | 默认值 | 含义 |
|---|---:|---|
| estimatedFeePct | 0.10 | 往返手续费预算 |
| estimatedSlippagePct | 0.05 | 往返滑点预算 |
| estimatedFundingPct | 0.01 | 预计持仓期间支付的资金费预算，不计收入 |
| maxEntryDeviationPct | 0.50 | 执行交易所参考价相对模型 entry_price 的最大偏离 |

预算不是实际费率，不保证真实成交成本。执行价是提交前 ticker 价格，市价最终成交仍可能滑动；本次没有增加订单成交回报/保护单核验系统。

计算公式（预算合计为 C）：

- 名义价值 = 资金基数 × position_pct /100 × leverage；按合约步长向下取整后复核金额。
- 风险金额 = 名义价值 × (stop_loss_pct + C)/100。
- 成本后盈亏比 = (take_profit_pct − C)/(stop_loss_pct + C)。
- 已用保证金取“持仓初始保证金估算”和“钱包余额 + 浮盈亏 − 可用资金”的较大非负值；无法确认持仓或杠杆时保守拒绝新增风险。

执行层拒绝超过策略/交易所杠杆、仓位、单笔风险、总保证金占用、最大持仓数的订单，也拒绝低信心度、不足最小金额、未知持仓/账户、缺必填开仓字段或执行价偏离过大的订单。止损与止盈以执行交易所参考价计算；附加止盈不受支持时拒绝当前开仓方案。

交易日按部署本地时区零点重置。程序统计当日账户净平仓结果：当前连亏两笔仓位上限减半；当日出现连续三笔亏损后停手状态锁定至次日。手续费未知或历史同步失败禁止开新仓，仍允许平仓。纪律和连续观望轮数直接注入，不要求模型从八条记忆推算。

## 第二轮优化：2026-10-13.2

- 不新增数据库列。每轮的 `DecisionJson._round` 保存 `status/failureStage/error/rawOutput/promptRevision/memoryFingerprint/requestSent`；失败动作是 `error`，不是 `hold`，不会进入成功决策记忆。数据准备失败时没有发送用户提示词、也没有模型响应，不伪造这些内容。历史失败轮次缺失的原文无法回补。
- 看板 HTTP/SSE 共用 DTO，追加轮次状态、错误、原始响应和规则版本；失败卡显示错误，confidence 显示评分而非百分比胜率。API 失败审计标记为失败，并记录具体原因。
- 记忆指纹包含规则版本、系统规则正文与完整策略配置；同策略、同交易员、同指纹的成功记录才注入。旧版本和配置变更的记录保留在历史中，但不再注入；连续观望计数也按当前指纹统计。失败轮次不计作观望。
- 新闻 JSON 使用可读中文并保留字符串/HTML 转义。启用完整原始表时省略重复结构摘要；关闭原始表时保留必要摘要，比例和变化率保留三位小数。
- 默认策略逐币表直接列出方向/动能/位置/成本后盈亏比、参考价/止损距离/最近结构目标及失败项。计算使用采样时已收盘 K 线，避免旧快照中的进行中 K 线因时间流逝被错误算作收盘。
- 回踩“触及”明确定义为 K 线 `[低,高]` 区间与 EMA±0.5ATR 区域相交，并要求收价位于均线相应一侧。突破需达到0.25ATR距离，或上一根弱突破在下一根收盘维持；三根同向累计超过3ATR时禁止突破追单。最近结构参考目标取主周期/方向周期最近20根已收盘K线的已确认三根摆动点，无目标即未知。
- OI、新闻和放量不是默认硬门槛。模型不能把辅助信息加成第五项要求，也不能把部分条件失败概括为所有条件失败；未来触发必须重新核对全部未满足项和成本后盈亏比。
- 空入场段或与当前默认入场正文完全相同的段落执行默认布尔校验；自定义入场段保留独立解释，默认表只作参考，资金硬风控仍然执行。
