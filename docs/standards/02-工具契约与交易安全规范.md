## 1. 原则

1. **工具是模型访问外部世界的唯一通道**。模型不得持有交易所 SDK、HTTP 客户端或数据库上下文。
2. **默认拒绝**：未列出的工具、未绑定的账户、未批准的提案、未命中的条件一律拒绝。
3. **服务端事实优先**：账户、持仓、价格、手续费、批准额度以服务端读取为准；模型参数只作为请求，不作为事实。
4. **写操作可审计**：每次写调用必须记录入参、判定、回执与错误码。
5. **不可信内容不进入控制流**：新闻、备注、外部 JSON 只作为数据；不得成为工具参数或权限依据。

## 2. 返回信封

所有工具返回统一 JSON 信封，**不得**把原始异常抛给模型：

```json
{
  "ok": true,
  "data": {},
  "asOfUtc": "2026-10-25T05:00:00.000Z",
  "source": "live",
  "warnings": [],
  "truncated": false
}
```

失败：

```json
{
  "ok": false,
  "error": {
    "code": "stale_market_data",
    "message": "行情采样时间超过 3 分钟，禁止开仓",
    "retryable": false
  },
  "asOfUtc": "2026-10-25T05:00:00.000Z"
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `ok` | bool | 是 | 业务成功与否 |
| `data` | object/array/string | `ok=true` 时必填 | 领域数据；表格类工具可为紧凑字符串 |
| `error.code` | string | `ok=false` 时必填 | 第 8 节的稳定错误码 |
| `error.message` | string | 是 | 可直接展示的中文文案 |
| `error.retryable` | bool | 是 | 是否鼓励模型重试 |
| `asOfUtc` | string | 否 | 数据采样时间（RFC 3339） |
| `source` | `live` / `incomplete` | 是 | 数据完整性 |
| `warnings` | string[] | 是 | 数据缺失、裁剪、降级 |
| `truncated` | bool | 是 | 结果是否被截断 |

- 预期业务失败**必须**返回信封，**不得**抛异常；未预期异常由工具中间件兜底为 `tool_internal_error`。
- 单次工具结果序列化后**不得超过** 16 KiB；超出按规则裁剪并置 `truncated=true`。
- 数值精度：价格 8 位有效数字，数量 8 位小数，百分比 2 位小数；展示时固定同样精度。

## 3. 工具注册与绑定

- 工具通过 `AIFunctionFactory.Create` 注册，名称使用 `snake_case`，参数名使用 `camelCase`。
- 工具类由单周期作用域构造，捕获 `TradingCycleContext`、`MarketDataCache`、`CycleRecorder`、账户锁与批准边界。
- 工具签名**不得**包含 `exchangeAccountId`、`traderId`、`apiKey`、`baseUrl` 等绑定参数。
- 每个角色只暴露其允许的工具；执行员之外的任何角色**不得**获得写工具。
- 工具清单版本纳入记忆指纹；新增/删除工具必须提升提示词修订号（LC-STD-04）。

内置新闻源（不写入策略配置、不新增工具/事件）：

| 来源 | 端点 | 鉴权 | 时间口径 | 轮次口径 |
| --- | --- | --- | --- | --- |
| 金十数据 | `GET https://flash-api.jin10.com/get_flash_list?channel=-8200&vip=1`（固定 `x-app-id` / `x-version` / 浏览器 UA） | 无 | 上游 `data[].time` 为北京时间（UTC+8，无时区标记），入库前归一为 ISO-8601 UTC（`Z` 结尾） | TTL 300s；每轮 ≤10 条（取最新）、每条 ≤200 字符；10s 超时、1MB 响应体上限 |

- 内置源与策略外部源并行拉取，合并后按（标题，或标题为空时正文前 40 字符；时间）去重；单源失败只在 `warnings` 记 `源 <名称> 缺席：<短中文原因>`，不抛异常、不影响其他源。
- 内置源**不依赖策略配置**：策略未配置任何外部源时仍拉取内置源并正常返回；`newsEnabled=false` 时整体关闭（内置源与配置源一并不拉取）。

**标的允许集合** = 策略候选池 ∪ 当前持仓 ∪ 窗口内已平仓标的。越界返回 `symbol_not_allowed`。分析师可访问候选池全部；交易员可访问允许集合；执行员只能访问提案标的与持仓。

## 5. 写工具

只允许以下三个写工具。**不得**新增提币、划转、改杠杆、改 API Key、改策略、改风控的工具。

### 5.1 `place_order`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `proposalId` | string | 是 | 本周期已获批提案 ID |
| `symbol` | string | 是 | 必须等于提案标的 |
| `side` | `long` / `short` | 是 | 必须等于提案方向 |
| `orderType` | `market` / `limit` | 是 | 市价需 `allowMarket=true` |
| `quantity` | number | 是 | >0；满足第 6 节第 6 步的保证金与数量校验 |
| `price` | number | `limit` 时必填 | 必须在 `[entryZoneMin, entryZoneMax]` |
| `leverage` | number | 否 | ≤ `maxLeverage`；缺省取 `maxLeverage` |
| `stopLossPrice` | number | 是 | 与方向一致 |
| `takeProfitPrice` | number | 否 | 与方向一致 |
| `reason` | string | 是 | ≤300 字，审计用 |

### 5.2 `close_position`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `proposalId` | string | 否 | 周期内 `close` 提案 ID；手动平仓省略；提供时必须匹配本周期 `close` 提案 |
| `symbol` | string | 是 | 必须持有该标的 |
| `quantity` | number | 否 | 缺省全部平仓；≤ 当前持仓 |
| `orderType` | `market` / `limit` | 是 | — |
| `price` | number | `limit` 时必填 | 与最新价偏差 ≤2% |
| `reason` | string | 是 | 审计用 |

平仓是风险降低操作，**不要求**提案与裁决；**必须**校验持仓存在、数量、行情新鲜度与重复提交。

### 5.3 `cancel_order`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `orderId` | string | 是 | 必须是本交易员创建且未成交的订单 |

**不得**允许取消其他交易员/其他账户的订单；已成交订单返回 `order_not_cancellable`。

## 6. 写工具硬闸顺序

`place_order` **必须**按以下顺序执行，任一步失败立即返回错误信封，后续步骤不得执行：

1. **模式**：周期 `Mode` 必须为 `dry` 或 `live`；未知模式拒绝。
2. **提案存在**：`proposalId` 属于本周期、本交易员、本策略。
3. **风控批准**：存在 `RiskVerdict` 且 `decision=approved`。
4. **未过期**：`now ≤ validUntilUtc`；裁决创建时已保证有效期 ≤10 分钟。
5. **账户重读**：在账户锁内重新读取账户与持仓；锁覆盖后续校验、提交与落库。
6. **边界与保证金校验**：
   - `leverage ≤ maxLeverage`；
   - 限价在价格带内；市价仅在 `allowMarket=true`；
   - 市价按最新价与提案 `entryPrice` 偏差 ≤ `maxPriceDeviationPct`（默认 0.5%）；
   - 保证金 `quantity × executionPrice / leverage ≤ equity × maxPositionPct / 100`，其中 `executionPrice` 为限价或最新价，`equity` 为第 5 步重读的当前权益。
7. **重跑风控**：用最新账户/持仓/价格调用 `TradingRiskPolicy.ValidateOpen`；失败返回 `risk_policy_violation`。
8. **行情新鲜度**：执行标的的最新行情采样 ≤3 分钟；否则 `stale_market_data`。
9. **重复与上限**：同 `proposalId` 已成功提交则返回已有订单；同标的 10 秒内重复开仓拒绝；每周期每标的最多 1 笔开仓；每周期写调用 ≤6。同一提案最多 2 次提交尝试；第二次**仅**用于交易所明确返回「未创建订单」的失败（如参数/杠杆校验失败），网络超时或结果未知**不得**重试。
10. **交易所校验**：标的（交易对）可交易、最小下单量/价格精度、杠杆设置成功、止损参数被交易所支持（实盘必须）；止盈参数若提供也必须支持；演练可模拟。任何一项未知→不提交。
11. **提交**：生成 `clientOrderId`；演练模式模拟成交，实盘调用 `ExchangeTradingService`。
12. **落库与推送**：实际提交或模拟成交写 `TraderOrder`（唯一索引 `(CycleId, ClientOrderId)`）；预提交拒绝只写 `ToolInvocation`；推送 `order` 与 `tool` SSE。

`close_position` 使用第 1、5、8、10、11、12 步；第 6 步改为校验持仓存在与数量，第 9 步只保留重复提交与写调用上限，第 10 步只校验交易对、数量精度与平仓能力。提供 `proposalId` 时**必须**校验其属于本周期且 `action=close`；手动平仓可省略。**不要求**裁决，不因「禁止开仓」拒绝。`cancel_order` 只校验订单归属、未成交状态、当前账户锁，并记录审计；不要求行情新鲜度。

## 7. 批准边界（仅 `open`）

本节只适用于 `place_order`（开仓）；`close_position` 不使用批准边界，只校验持仓、数量、新鲜度与重复。

- 风控输出**只能收紧**：`maxPositionPct ≤ proposal.positionPct`、`maxLeverage ≤ proposal.leverage`。
- 保证金上限与数量上限按执行时重读的权益计算：

```text
approvedMaxMargin = equity × maxPositionPct / 100
submittedMargin   = quantity × executionPrice / leverage
约束：submittedMargin ≤ approvedMaxMargin 且 leverage ≤ maxLeverage
等价数量上限：approvedMaxQuantity(leverage) = approvedMaxMargin × leverage / executionPrice
```

  数量按交易所精度向下取整；**不得**使用批准时的旧权益快照放宽执行时额度。
- `entryZoneMin/Max` 必须包含提案 `entryPrice` 附近的可成交区间；限价越界拒绝。
- 裁决创建时 `validUntilUtc ≤ approvedAt + 10 分钟`；写工具在 `now ≤ validUntilUtc` 时允许，超过拒绝。过期后执行员**不得**自行延期，只能在下个周期重新提案。
- 风控拒绝后，执行员**不得**收到该提案；工作流直接进入终态。

## 8. 错误码

| 错误码 | 触发 | 可重试 |
| --- | --- | --- |
| `symbol_not_allowed` | 标的不在允许集合 | 否 |
| `position_not_found` | 无该标的持仓 | 否 |
| `invalid_argument` | 参数缺失/类型/范围错误 | 否 |
| `data_unavailable` | 关键行情/账户数据不可得 | 是（有限） |
| `stale_market_data` | 行情超过 3 分钟 | 否（等待下个周期） |
| `proposal_not_found` | 提案不存在或不属于本周期 | 否 |
| `proposal_not_approved` | 无批准裁决或已拒绝 | 否 |
| `proposal_expired` | 超过 `validUntilUtc` | 否 |
| `quantity_exceeded` | 保证金或数量超过批准边界，或平仓数量超过持仓 | 否 |
| `leverage_exceeded` | 超过 `maxLeverage` | 否 |
| `price_out_of_band` | 限价/市价偏差越界 | 否 |
| `risk_policy_violation` | 重跑风控失败 | 否 |
| `duplicate_order` | 重复提交 | 是（返回已有订单） |
| `order_limit_reached` | 每周期订单数超限 | 否 |
| `order_not_cancellable` | 订单已成交或不属于本交易员 | 否 |
| `tool_budget_exceeded` | 工具调用超预算 | 否 |
| `exchange_error` | 交易所明确拒绝 | 视错误码；仅明确未创建订单可重试 |
| `exchange_unknown` | 交易所结果未知 | 否（人工核对） |
| `tool_internal_error` | 工具未预期异常 | 否（写工具）；只读可重试一次 |

错误文案**必须**可直接展示给用户；不得包含堆栈、SQL、上游地址、Key。

## 9. 幂等与重复

- `clientOrderId` 必须确定性、≤36 字符，包含周期短标识、订单键与尝试序号：
  - 订单键：有提案时用 `proposalId`；手动平仓用 `close-{symbol}`；
  - 示例：`lc-{cycleId 后 12 位}-{订单键 SHA256 前 8 位}-{attempt}`；
  - 同一 attempt 的网络层重试**必须**复用同一键；业务层重新提交**必须**递增 attempt，且只能在上一 attempt 明确未创建订单时进行。
- 数据库唯一索引 `(CycleId, ClientOrderId)` 兜底；重复插入返回已有订单。
- 交易所写请求**不得**挂自动重试/弹性管道；重试只能由工具按本节规则显式执行。
- 交易所返回「重复订单」时按成功处理并记录 `duplicate_order` 警告，不重复提交。
- 每周期每标的开仓最多 1 笔；结果未知（`exchange_unknown`）**不得**重试，必须人工核对。

## 10. 演练与实盘

| 项目 | 演练 `dry` | 实盘 `live` |
| --- | --- | --- |
| 交易所下单 | 不调用 | 调用 |
| 成交模拟 | 最新价 + 配置手续费/滑点 | 以交易所回执为准 |
| `TraderOrder.simulated` | `true` | `false` |
| 订单状态 | 模拟成交为 `filled`；失败为 `failed` | 以交易所回执为准（`submitted` / `filled` / `partial` / `failed` / `unknown` / `cancelled`） |
| SSE/UI | 标注「演练」 | 标注「实盘」 |
| 风控/硬闸 | 全部执行 | 全部执行 |
| 默认值 | 新建交易员默认 | 需显式切换 |

**不得**在演练模式下把模拟成交写成真实成交；成交明细未核实时必须写「请求成功，成交未核实」。

## 11. 审计

每次调用**必须**落 `ToolInvocation`：

| 字段 | 说明 |
| --- | --- |
| `cycleId` / `stageRunId` | 关联 |
| `toolName` | 工具名 |
| `argumentsJson` | 入参；Key/Secret 脱敏 |
| `resultJson` | 回执；>16 KiB 截断 |
| `success` | 业务成功 |
| `errorCode` | 失败码 |
| `elapsedMs` | 耗时 |
| `createdAt` | UTC |

写工具与失败调用**必须**推送 `tool` SSE；只读成功调用只在阶段完成时汇总，避免高频事件。

## 12. 威胁模型

| 威胁 | 场景 | 防线 |
| --- | --- | --- |
| 模型幻觉订单 | 编造标的/数量/价格 | 只认 `proposalId`；边界校验；硬闸 |
| 参数篡改 | 执行员放大数量/杠杆 | 批准边界 + 服务端换算 + 重跑风控 |
| 过期提案重放 | 复用旧批准 | `validUntilUtc` + 周期绑定 + 提案归属校验 |
| 跨账户访问 | 模型传其他账户 ID | 工具无账户参数；作用域绑定 |
| 重复下单 | 重试/网络抖动 | `clientOrderId` + 唯一索引 + 10 秒去重 |
| 陈旧数据 | 用旧行情开仓 | 3 分钟新鲜度 + 账户重读 |
| Prompt injection | 新闻/外部数据含指令 | 不可信包裹；写工具只认服务端事实；风控不读自由文本 |
| 密钥泄漏 | 日志/提示词/工具入参 | 脱敏；不入模型上下文；不记录请求头 |
| 成本失控 | 工具循环 | 工具/周期/token 上限；超限观望 |
| 越权运维 | 远程调用本地 API | 仅监听 localhost；远程部署前必须加认证与加密 |

## 13. 验收判据

1. 未批准、已拒绝、过期、超数量、超杠杆、价格越界、陈旧行情、重复提交、跨账户、越界标的十类拒绝均有单测。
2. 演练模式无交易请求（行情只读允许）；实盘路径由假网关验证调用次数与顺序。
3. `(CycleId, ClientOrderId)` 唯一约束生效；重复调用返回同一订单。
4. 工具结果 16 KiB 截断、阶段消息 128 KiB 截断均有测试。
5. 密钥脱敏测试覆盖工具入参、回执、日志、提示词。
6. 风控收紧换算有边界测试：保证金按执行时权益与实际杠杆计算、精度向下取整、权益下降自动收紧；行情年龄 3 分钟整允许、超过拒绝；`now == validUntilUtc` 允许。
