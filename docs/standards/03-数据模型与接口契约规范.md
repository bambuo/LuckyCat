## 1. 通用约定

### 1.1 JSON

- 字段名 **camelCase**；枚举值 **camelCase 字符串**；不得混用 snake_case。
- **金额、数量、百分比、杠杆一律以字符串传输**（如 `"123.45"`、`"2.5"`），服务端 `decimal` 解析；模型输出可用数字，但入库前转为 `decimal` 并按精度校验。
- 百分比以**百分点**表示：`"1"` = 1%。
- 时间统一 UTC、RFC 3339、毫秒精度：`"2026-10-25T05:00:00.000Z"`。前端负责本地化展示。
- `null` = 未知/未提供；空数组 `[]` = 有数据集但为空；零值对象 = 统计存在且为 0。三者不得互相替代。
- 标识：数据库实体用整数 `id`；周期、阶段、提案、裁决用字符串 ID（ULID）；订单同时有整数 `orderId` 与交易所 `clientOrderId`。
- 请求体不得包含多余字段（`JsonSerializerOptions.UnmappedMemberHandling = Disallow`）；非法枚举、非法范围一律 4xx，不静默取默认值。

### 1.2 响应包裹

成功：

```json
{
  "success": true,
  "data": {}
}
```

失败：

```json
{
  "success": false,
  "error": {
    "code": "risk_limit_exceeded",
    "message": "该提案超过风控允许的最大仓位，已拒绝"
  }
}
```

| HTTP | 用途 |
| ---: | --- |
| 200 | 读取/更新成功 |
| 201 | 创建成功 |
| 204 | 删除成功，无响应体 |
| 400 | 字段缺失、类型/范围/枚举非法 |
| 404 | 资源不存在 |
| 409 | 状态冲突（运行中、重复操作、周期进行中） |
| 422 | 业务规则拒绝（风控、能力不足、参数组合非法） |
| 500 | 未预期异常；文案固定「服务内部错误，请稍后重试」 |

- 错误 `message` **必须**可直接展示给用户；不得包含堆栈、SQL、上游地址、Key。
- 同一错误码在不同端点语义一致；错误码见第 6 节。

### 1.3 列表与分页

```json
{
  "success": true,
  "data": {
    "items": [],
    "total": 0,
    "page": 1,
    "pageSize": 20
  }
}
```

- `page` 从 1 起；`pageSize` 默认 20，最大 100；`pageSize=0` 非法（400）。
- 排序参数 `sort=field:asc|desc`，字段白名单；越界/非法字段 400。
- 空列表返回 `items: []` 且 `total: 0`，不得返回 `null`。

### 1.4 写操作

- 创建返回 201 + 完整资源；更新返回 200 + 完整资源。
- 幂等：`POST /traders/{id}/start|stop` 按状态幂等；`POST /traders/{id}/reviews/run` 60 秒内重复请求返回 409 `review_in_progress`；订单写工具幂等见 LC-STD-02。
- 删除策略/提供商/交易员前必须校验引用；被引用返回 409 `resource_in_use`，不得级联删除。

### 2.2 修改

#### `TraderOrder`（扩展）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `proposalId` | string? | 关联提案 |
| `verdictId` | string? | 关联裁决 |

#### `Provider`（扩展）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `toolCallingSupported` | bool? | 工具调用验证结果；启动交易员前必须为 true |
| `toolCallingVerifiedAt` | datetime? | 最近验证时间 |

#### `StrategyConfig`（重构）

- 删除：`strategyType`、`grid`。
- 保留：`coinSource`、`indicators`、`riskControl`、`promptSections`、`customPrompt`、`decisionMemoryEnabled`、`newsEnabled`。
- 新增：`roleInstructions`（`analyst`/`trader`/`risk`/`executor`/`reviewer` 的追加指令，各 ≤2,000 字）、`agentBudget`（超时、工具上限、token 预算）、`review`（`enabled`、`localTime`、`maxLookbackDays`）。
- `agentBudget` 默认值见 LC-STD-01 第 6 节；`review` 默认 `{ enabled: true, localTime: "00:10", maxLookbackDays: 30 }`。

### 2.3 保留

`Provider`（除扩展字段）、`ExchangeAccount`、`Strategy`、`Trader`、`PositionHistory`、`AccountEquitySample`、`AccountPositionSnapshot` 保留。`Trader.ExecutionMode` 新记录默认 `dry`（D-13）。

### 2.4 删除

`DecisionRecord` 删除。数据库文件直接删除重建（`EnsureCreated`），不写迁移；旧数据库不提供导入。

### 2.5 数据保留

| 数据 | 保留 | 清理 |
| --- | --- | --- |
| `TradingCycle` | 永久 | 不清理（体积小） |
| `AgentStageRun` | 90 天 | 每日 03:30 本地时间清理 |
| `ToolInvocation` | 90 天 | 同上 |
| `TradeProposal` / `RiskVerdict` / `TraderOrder` / `TraderLesson` | 永久 | 不清理 |
| 权益/持仓采样 | 沿用现状 | 沿用现状 |

清理任务**不得**删除仍被保留实体引用的行；若外键冲突，跳过并记录日志。

| POST | `/strategies/test-run` | SSE：演练模式运行完整工作流 |

`test-run` 请求：

```json
{
  "strategyId": 1,
  "providerId": 2,
  "accountId": null,
  "testEquity": "10000",
  "includeMemory": true
}
```

- `accountId=null` 时使用合成账户（权益 `testEquity`、无持仓、无订单），**不得**调用交易所。
- 指定 `accountId` 时只读真实账户；仍为演练，不下单。
- 生成 `TradingCycle`：`traderId=null`、`trigger=test`、`mode=dry`。
- Provider 未通过工具调用验证返回 422 `provider_capability_missing`。

## 4. SSE

### 4.1 帧格式

```text
event: stage
data: {"cycleId":"01J...","role":"risk","status":"completed"}

```

- `Content-Type: text/event-stream`；每条事件以空行结束。
- 心跳 `ping` 每 15 秒；连接空闲 45 秒无数据视为断线，客户端重连。
- 不提供断线重放；客户端重连后重新拉取 `/traders/{id}/dashboard` 与最新周期。
- 事件 `data` 一律单行 JSON（格式化由前端负责展示）。

### 4.2 事件

| 事件 | 触发 | 载荷 |
| --- | --- | --- |
| `state` | 连接建立、启停 | `{ isRunning, lastCycleStatus, lastCycleAt }` |
| `cycle` | 周期开始/结束 | `{ cycleId, traderId, mode, trigger, status, startedAt, completedAt, error }` |
| `stage` | 阶段完成/失败 | `{ cycleId, stageId, role, status, attempt, elapsedMs, inputTokens, outputTokens, toolCalls, summary, error }` |
| `plan` | 提案生成 | `TradeProposal` 完整对象（字符串数值） |
| `risk` | 裁决生成 | `RiskVerdict` 完整对象 |
| `tool` | 写工具调用或工具失败 | `{ cycleId, stageId, tool, success, errorCode, elapsedMs, at }` |
| `order` | 订单提交/失败 | `{ orderId, proposalId, action, side, symbol, quantity, price, status, simulated, note, at }` |
| `equity` | 净值采样 | `{ equity, at }` |
| `history` | 平仓历史同步 | `{ positionHistoryId, symbol, realizedPnl, closeTime }` |
| `ping` | 心跳 | `{ at }` |

- `tool` 事件不携带入参/回执全文；需要详情时经 `/cycles/{id}` 查询。
- `plan` / `risk` 事件中的数值字段仍为字符串，与 REST 一致。

## 6. 错误码

| 域 | 错误码 | HTTP | 文案要求 |
| --- | --- | --- | --- |
| 通用 | `validation_failed` | 400 | 点名字段与范围 |
| 通用 | `not_found` | 404 | 说明对象类型 |
| 通用 | `resource_in_use` | 409 | 说明被谁引用 |
| 通用 | `conflict` | 409 | 说明当前状态 |

## 7. 兼容性与变更

- **上线前**（当前）：契约可自由重设计；每次变更同步本文档与设计规格版本。
- **上线后**：字段只增不删；枚举只增不改义；新参数必须可选且缺省行为等于旧行为；破坏性变更需要新路径或版本前缀。
- 契约变更**必须**同时更新：本文档、LC-SPEC-001 差异清单、前端对接文档、示例 JSON。
- `success`/`data`/`error` 包裹结构不得按端点变化。

## 8. 验收判据

1. 所有端点返回统一包裹；4xx/5xx 文案符合第 6 节。
2. 金额/数量/百分比在 REST 与 SSE 中均为字符串；前端不做浮点运算。
3. 列表分页、空结果三语义、404/409/422 各有测试。
4. SSE 事件名与载荷字段和本规范逐字一致；心跳可观测。
5. `test-run` 使用合成账户时不产生任何交易所请求，且周期 `trigger=test`。
6. 数据库从空库重建成功；`DecisionRecord` 不再存在。
7. 清理任务只删除 90 天前的阶段与工具记录，不破坏保留实体。
