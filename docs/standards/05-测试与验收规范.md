## 1. 原则

1. **先证据后结论**：没有命令输出、测试报告或浏览器实测，不得声称通过。
2. **默认不连外网**：单测与集成测试不访问真实模型、交易所、新闻源。
3. **真实工作流**：集成测试运行真实的 `WorkflowBuilder` 图与真实工具硬闸，只替换模型与交易所边界。
4. **保留纯函数基线**：现有 `TradingRiskPolicy` 测试不改断言；行为变更必须先改规范版本。
5. **写测试必须可重复**：固定时间、固定随机源、固定精度；不使用当前时间作为断言输入。

## 2. 测试分层

| 层 | 范围 | 依赖 | 运行时机 |
| --- | --- | --- | --- |
| 单元 | 风控换算、边界校验、信封、提示词构建、记忆指纹、解析器、预算 | 无 IO | 每次提交 |
| 工作流 | 六条路由、阶段失败、终态、审计落库 | 内存 SQLite + 脚本化模型 + 假网关 | 每次提交 |
| HTTP | 端点、包裹、状态码、分页、SSE 帧 | 临时宿主 + 内存 SQLite | 每次提交 |
| 前端 | 类型检查、构建、关键页面 | Bun | 每次提交 |
| 联调 | 真实 Provider（演练）、真实看板 | 本地服务 | 阶段验收 |
| 实盘 | 真实交易所（可选） | 人工授权 | 上线前单独执行 |

## 3. 注入缝

| 缝 | 接口/类型 | 用途 |
| --- | --- | --- |
| 模型 | `IChatClient`（通过 `IAgentFactory` 创建） | 脚本化每角色的工具调用与最终 JSON |
| 模型工厂 | `IAgentFactory` | 测试替换，避免真实网络 |
| 交易所写 | `IExchangeExecutionGateway`（`PlaceAsync` / `CloseAsync` / `CancelAsync` / `SetLeverageAsync` / `GetPositionModeAsync`） | 记录调用、模拟失败、验证顺序 |
| 交易所读 | `IMarketDataReader`（行情/账户/持仓/订单） | 固定快照与陈旧数据 |
| 时间 | `TimeProvider` | 固定 UTC 时间、有效期/新鲜度 |
| 时钟调度 | `TimeProvider.CreateTimer` 或测试直接调用 | 避免后台循环 |
| 数据库 | 内存 SQLite（`DataSource=:memory:`，每测试独立连接） | 真实 EF 行为 |
| SSE | 真实 HTTP 读取 | 校验事件名与帧格式 |

- 脚本化模型**必须**走真实的 `ChatClientAgent` 工具循环：先返回 `FunctionCallContent`，再返回最终 JSON，以覆盖工具调用、预算与中间件。
- 假网关**不得**被业务代码直接引用；只通过接口注入。

## 4. 必测矩阵

### 4.1 风控与执行（保留 + 扩充）

| 编号 | 场景 |
| --- | --- |
| RISK-01~25 | 现有 `TradingRiskPolicyTests` 全部保留，不改断言 |
| EXEC-01 | 保证金按执行时权益与实际杠杆换算；数量按交易所精度向下取整 |
| EXEC-02 | 权益下降后重跑风控进一步收紧 |
| EXEC-03 | 数量/杠杆/价格带越界分别拒绝 |
| EXEC-04 | 过期提案拒绝；`now == validUntilUtc` 允许，超过拒绝 |
| EXEC-05 | 限价/市价、`allowMarket` 组合 |
| EXEC-06 | 平仓不受停手限制；无持仓返回 `position_not_found`；仍校验数量与新鲜度 |
| EXEC-07 | 手动平仓创建 `trigger=manual` 周期，复用写工具硬闸并审计 |

### 4.2 工具

| 编号 | 场景 |
| --- | --- |
| TOOL-01 | 未批准/已拒绝提案调用 `place_order` 拒绝 |
| TOOL-02 | 跨周期/跨交易员提案拒绝 |
| TOOL-03 | 越界标的拒绝 |
| TOOL-04 | 陈旧行情拒绝：年龄 3 分钟整允许，超过拒绝 |
| TOOL-05 | 同周期重复 `clientOrderId` 返回已有订单；跨周期同 ID 不冲突 |
| TOOL-06 | 每周期订单数/工具调用上限 |
| TOOL-07 | 演练模式零交易请求（行情只读允许），订单 `status=filled` 且 `simulated=true` |
| TOOL-08 | 实盘调用顺序：设杠杆 → 持仓模式 → 提交 |
| TOOL-09 | 交易所结果未知标记 `unknown`，不自动重发 |
| TOOL-10 | 结果 >16 KiB 截断；入参脱敏 |
| TOOL-11 | 工具异常转为 `tool_internal_error` 信封，不泄漏堆栈 |
| TOOL-12 | 取消非本交易员订单拒绝 |
| TOOL-13 | 交易所写请求不经过全局自动重试；`exchange_unknown` 不重发 |

### 4.3 工作流

| 编号 | 场景 |
| --- | --- |
| FLOW-01 | 无候选 → `skipped`，无提案 |
| FLOW-02 | `hold` → 不进风控，周期 `completed` |
| FLOW-03 | 开仓被风控拒绝 → 不进执行，写入裁决 |
| FLOW-04 | 开仓批准 → 执行 → 订单落库 + SSE |
| FLOW-05 | 写工具拒绝 → 周期完成但 `errors` 非空 |
| FLOW-06 | 分析师异常 → `failed`；自身超时 → `stage_timeout`，无后续调用 |
| FLOW-07 | 交易员契约失败 → 重试 1 次；仍失败 `failed` |
| FLOW-08 | 风控超时 → `stage_timeout`，fail-closed，不下单 |
| FLOW-09 | 总预算超限 → 停止后续阶段，本周期观望 |
| FLOW-10 | 同交易员并发启动只产生一个周期 |
| FLOW-11 | 同账户两交易员写操作串行 |
| FLOW-12 | 停止交易员取消周期并记录 `aborted` |
| FLOW-13 | 重启后遗留 `running` → `aborted`，交易员恢复 |
| FLOW-14 | `close` 跳过风控直接执行；无 `RiskVerdict` 仍可平仓 |

## 5. 验收闸门

| 闸门 | 命令/操作 | 通过标准 |
| --- | --- | --- |
| G1 构建 | `dotnet build` | 0 error；警告需解释 |
| G2 测试 | `dotnet test Tests/LuckyCat.Tests.csproj` | 全绿；无跳过（环境变量缺失的联调测试除外） |
| G3 前端 | `cd web && bun install --frozen-lockfile && bun run build` | 类型检查与构建通过 |
| G4 工作流 | 集成测试六条路由 + 阶段超时 | FLOW-01~05、FLOW-08、FLOW-14 全绿 |
| G5 真实演练 | 启动服务，选择真实 Provider，`test-run` + 交易员 `dry` 周期 | 至少一个周期；阶段事件按实际路径齐全（开仓含风控，平仓跳过风控）；SSE 无断流；无交易/账户请求（行情只读允许） |
| G6 浏览器 | 看板、工作室预览、试运行、周期历史、复盘 | 页面可见、可交互、无控制台错误 |
| G7 安全 | 清单核对 | 密钥脱敏、localhost、日志无凭据、写工具越权被拒 |
| G8 运维 | 空库启动、运行中重启、备份恢复 | 周期终态正确、恢复调度、无 `running` 残留 |

- G5 必须记录 `cycleId`、模型名、token、耗时；G6 必须附截图。
- 任一闸门失败不得进入下一阶段；修复后从 G1 重跑。

## 6. 证据要求

- 命令类：完整命令 + 退出码 + 关键输出（不得只写「已通过」）。
- 测试类：测试总数、通过数、失败数；新增测试列出编号。
- 浏览器类：截图 + 操作路径；SSE 用浏览器网络面板或日志证明事件到达。
- 真实演练：周期详情链接/JSON + 日志片段；不得伪造 token 或耗时。
- 安全类：脱敏前后样例（Key 用 `<redacted>`）、越权拒绝的错误码。

## 7. 回归与变更纪律

- 现有 25 项风控测试**必须**保留；如需修改断言，必须先在 LC-STD-01/02 记录行为变更并升版本。
- 删除旧测试时必须在提交说明中列出被删除的测试与替代用例。
- 测试夹具不得包含真实 API Key、账户 UID、订单号；使用占位符。
- 失败重试不得用「跳过」掩盖；环境缺失的联调测试必须显式 `Skip` 并说明原因。

## 8. 实盘测试安全

仅在以下条件全部满足时执行：

1. 产品负责人明确授权；
2. 使用专用小额账户与白名单 Key；
3. 交易员 `live`、单笔风险最小、只允许一个标的；
4. 只运行一个周期，结束后立即停止；
5. 记录订单 ID、成交回执与账户快照；
6. 失败时先停止交易员，再排查，不得自动重试。
