## 1. 锁定规则

1. 依赖版本以 `版本清单.json` 为机器可读事实源，本文档为解释与理由。
2. 只使用 **GA 稳定版**；预览版（prerelease）必须经书面批准并记录风险，当前禁止 `Microsoft.Agents.AI.Hosting*`。
3. NuGet 采用精确版本；升级必须一次一个包族，并重跑 LC-STD-05 的 G1–G4。
4. 前端依赖保留 `package.json` 范围 + `bun.lock` 锁定；构建使用 `bun install --frozen-lockfile`。
5. `global.json` **必须**锁定 SDK `10.0.302`；升级 SDK 视为依赖升级。
6. 建议开启 NuGet 锁定文件（`RestorePackagesWithLockFile=true`），保证传递依赖可复现。
7. 每个版本升级**必须**同步更新本文档、`版本清单.json` 与相关设计/规范版本。

## 6. 升级流程

1. 阅读目标版本 release notes 与迁移指南；确认是否有破坏性变更。
2. 更新 `版本清单.json` 的候选版本与核对日（先不合并）。
3. 在分支升级，运行 G1–G4；涉及模型/工具时补跑 G5。
4. 更新本文档（版本号按 LC-STD-00 规则递增）与受影响的 LC-SPEC/LC-STD。
5. 在变更历史记录：旧版本、新版本、影响面、验证结果。
6. 复核 `docs/standards/版本清单.json` 与实际 `csproj`/`package.json` 一致。

## 7. 复核清单（每 90 天）

- [ ] NuGet 最新稳定版与当前版本差异；是否有安全公告。
- [ ] MAF 文档是否有破坏性 API 变更；Hosting 是否转 GA。
- [ ] OpenTelemetry GenAI 语义约定是否改名/改单位。
- [ ] 前端依赖是否有安全更新；`bun.lock` 是否可复现构建。
- [ ] 外部标准链接是否可达；`Living` 文档是否影响本规范。
- [ ] 版本清单 `review.nextReviewDue` 是否顺延。

## 8. 验收判据

1. `版本清单.json` 可被 JSON 解析，字段与本文档一致。
2. `dotnet restore` 无版本冲突；`Microsoft.Extensions.AI.Abstractions` ≥10.10.1。
3. 未引入任何 prerelease 包。
4. `web/bun.lock` 与 `package.json` 一致，冻结安装可构建。
5. 每个外部标准都有链接、核对日与用途。
