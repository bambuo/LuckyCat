# 日内顺势回调（稳健验证）

配置日期：2026-10-13；配置结构已对齐多智能体交易链路。

这是一套待验证的配置，以提高入场质量为目标，没有实测胜率或收益结果。保存为独立策略，不自动激活、不绑定或启动交易员。配置不包含交易员的执行模式、逐仓设置和扫描间隔；绑定时须单独检查这些设置，Gate 策略应绑定 Gate 账户。

## 示例文件

| 文件 | 用途 |
| --- | --- |
| `intraday-trend-pullback.json` | 推荐导入文件，可直接在「策略工作室 → 导入」使用，或 `POST /api/strategies` |
| `intraday-trend-pullback-saved.json` | 已保存策略的再导入副本，配置与导入文件一致，用于备份或迁移到其他实例 |
| `intraday-trend-pullback-preview.json` | 五角色提示词预览副本；`roleInstructions` 为示例文本，正式保存前可按需修改或清空 |

三份文件都使用当前 `StrategyConfig`（camelCase），字段与后端模型、工作室类型一致，并显式给出 `roleInstructions`、`agentBudget` 与 `review`。导入只校验配置结构与风控参数，不激活策略、不绑定交易员，也不会调用模型。

## 参数

| 项目 | 配置 |
| --- | --- |
| 标的与行情 | Gate USDT永续：BTC、ETH；固定池 |
| 周期 | 1h方向，15m入场；主周期展示64根K线，指标另有预热数据 |
| 指标 | EMA20/50、MACD12/26/9、RSI14、ATR14、成交量、资金费 |
| 持仓 | 最多1仓，不加仓；最多3倍杠杆 |
| 保证金 | 单仓上限10%，合计上限15%；连亏两笔后单仓上限5% |
| 单笔风险 | 含成本预算不超过账户资金基数0.5% |
| 盈亏比 | 扣除成本后至少1.5 |
| 成本预算 | 往返手续费0.15%、往返滑点0.05%、预计支付资金费0.01% |
| 执行偏离 | 执行价相对参考价不超过0.15% |
| 最小名义金额 | 12 USDT，另受交易所数量步长和最小量约束 |
| 信息输入 | 关闭新闻与历史决策记忆注入，保留原始K线 |
| 五角色追加指令 | 基础与已保存文件为空；预览文件为示例文本 |
| 智能体预算 | 阶段超时 90/90/45/45 秒、周期 300 秒；工具上限 20/10/4/6、周期 45；输入 token 150,000 |
| 每日复盘 | 开启，服务器本地时刻 00:10，最多回看 30 天 |

五角色追加指令分别写入 `roleInstructions.analyst` / `trader` / `risk` / `executor` / `reviewer`，只追加在对应角色提示词末尾，不能覆盖风控、工具与输出契约。`agentBudget` 显式写出新默认值，便于核对；省略时后端使用同一组默认值。复盘配置只影响该策略绑定交易员的自动复盘调度，手动复盘仍可在复盘页触发。

费用为估算，未读取用户账户实际费率。配置时Gate公开BTC/ETH合约规格返回单边Taker费率0.075%，据此往返预算设为0.15%。交易费取决于maker/taker和账户等级；资金费取决于结算时点持仓与合约费率。公开合约规格只用于检查可交易性及预算，不等同于账户费率。

## 入场和退出

保留空白`promptSections.entry`，沿用默认入场规则，避免切换成自定义入场而绕开默认程序校验：方向、动能、位置与最近结构目标的成本后盈亏比必须达标。

附加提示进一步要求：1h均线间距至少0.25ATR；最新15m收盘K线回调至EMA20附近并收回顺势方向；阳线确认多头、阴线确认空头；当前价离EMA20不超过0.75ATR；仅突破不入场。固定ATR×1.5止损不能覆盖回调结构时放弃，不能缩止损或拉远目标凑比例。

额外回调、均线间距和结构覆盖过滤属于交易员提示词要求，当前没有独立程序硬校验。资金、数量、杠杆、批准边界与写工具校验由执行链路强制；提示词预览与试运行只证明当前服务能构建对应角色的提示词并运行真实工作流，不证明模型每次都遵守附加规则。

有持仓优先处理结构失效和保护状态，不按单次RSI波动随意退出。预期持仓60–180分钟，不设最低交易次数，也没有定时强平或禁止隔夜的硬功能。连续两笔净亏损减半、三笔停止新开仓使用系统已有纪律。本配置没有新增每日累计亏损硬限额或收盘时间调度功能。

## 金额与成本示例

按资金基数100 USDT、保证金10%、杠杆3倍计算，名义金额约30 USDT。止损0.8%、成本预算0.21%时，预计风险约0.303 USDT（0.303%），净盈亏比1.5要求目标距离至少1.725%。实际使用最近结构目标；若空间不足则观望。

仓位上限须同时满足`position_pct ≤ 100 × 0.5 / [leverage × (stop_loss_pct + 0.21)]`、配置上限及系统连亏折扣。连亏减半后，100 USDT账户的最大名义金额约15 USDT；数量取整或净值降低可能使金额低于12 USDT，此时停止开仓，不突破风险补足。

配置时公开合约规格：BTC每张0.0001 BTC，ETH每张0.01 ETH。按当时标记价格约83,486.7和2,508.18 USDT估算，每张名义金额约8.35和25.08 USDT。30 USDT上限分别只能容纳3张BTC或1张ETH；减半至15 USDT时BTC一张低于策略12 USDT门槛、ETH不足一张，两者都会被拒单。这意味着小账户可能在连续两笔亏损后提前停手，而不是必然能进行第三笔。实际数量、步长和价格以执行器重新读取的交易所规格为准，不为保持交易频率提高仓位。

## 验证和启用边界

三份示例文件均已通过运行中服务的`POST /api/strategies`导入校验，并在校验后删除（删除返回 204）。这只证明配置结构、字段命名与风控参数可被工作室接受，不证明模型遵守附加规则，也不证明策略盈利。未调用模型、未做历史回测、未下单。

启用前应以非实盘方式核对真实模型输出与 Gate 行情；按每次开仓是否满足规则、扣费净胜率、平均净盈亏、期望值、最大回撤和拒单原因评估。不得为了增加成交而单独降低盈亏比或扩大止损。

绑定交易员时确认 Gate 账户、逐仓设置、扫描间隔（3–60 分钟）以及执行模式。策略按已收盘 K 线判断，扫描间隔早于 K 线收盘时会重复读取同一根已收盘 K 线，属于正常现象。
