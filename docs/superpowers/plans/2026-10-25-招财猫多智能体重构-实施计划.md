# 招财猫多智能体重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 Microsoft Agent Framework 1.26 重建招财猫的交易链路：四段交易工作流（分析 → 交易 → 风控 → 执行）+ 独立复盘，工具取数、写工具硬闸、完整审计、新数据/接口/前端。

**Architecture:** 每个交易员周期构建一张 `WorkflowBuilder` 图，四个 `ChatClientAgent` 阶段通过类型化消息与条件边连接；工具由单周期作用域构造，交易所写操作只能经过 `place_order` / `close_position` / `cancel_order` 的固定硬闸；`close` 跳过风控，`open` 必须持有 `RiskVerdict`。旧单轮链路在 P7 删除，不保留运行时开关。

**Tech Stack:** .NET 10.0.302、`Microsoft.Agents.AI` 1.26.0、`Microsoft.Agents.AI.Workflows` 1.26.0、`Microsoft.Extensions.AI` 10.10.x、EF Core SQLite 10.0.12、xUnit、Vue 3 + Vite + Arco Design + Bun。

**Spec:** [LC-SPEC-001](../specs/2026-10-25-招财猫多智能体重构-设计.md) 与 LC-STD-00~06（实现时同时阅读；规范优先于本计划中的示例代码）。

## Global Constraints

- 目标框架 `net10.0`；SDK 锁定 `10.0.302`；禁止引入 `Microsoft.Agents.AI.Hosting*`（prerelease）。
- 角色：`analyst` / `trader` / `risk` / `executor` / `reviewer`；四个交易角色与复盘员共用交易员绑定的 Provider/模型。
- `open` 必须经风控裁决；`close` 跳过风控；平仓仍必须经过写工具硬闸。
- 周期状态只有 `running` / `completed` / `failed` / `skipped` / `aborted`；用户停止记 `aborted` + `errorCode=cancelled_by_user`。
- 风控失败 fail-closed：周期 `failed`、不写 `RiskVerdict`、不下单。
- SSE 事件只有 `state` / `cycle` / `stage` / `proposal` / `verdict` / `tool` / `order` / `equity` / `position-history` / `ping`。
- 工具错误码使用 `proposal_not_found` / `proposal_not_approved` / `proposal_expired` / `tool_internal_error` / `position_not_found` / `order_not_cancellable`；不得使用 `plan_*`。
- REST/SSE 字段 camelCase；金额、数量、百分比、杠杆以字符串传输；时间 UTC RFC 3339 毫秒精度。
- 写工具硬闸顺序：模式 → 提案 → 裁决 → 有效期 → 账户重读 → 边界/保证金 → 重跑风控 → 新鲜度 → 重复/上限 → 交易所能力 → 提交 → 落库推送。
- 保证金约束：`quantity × executionPrice / leverage ≤ equity × maxPositionPct / 100`，权益用执行时重读值，杠杆用执行员实际选择值。
- 交易所写请求不得挂全局自动重试；结果未知不重试。
- 预算：阶段超时 90/90/45/45s，总超时 300s；工具上限基础 20/14/4/6 且分析师/交易员随标的数放大（+4/+3 每标的）、周期总量按实际上限之和；输入预算 `min(150,000, ContextTokens − effectiveMaxOutputTokens)`，下限 1,000；阶段消息 128 KiB、工具结果 16 KiB 截断。
- 复盘单次超时 120s、工具上限 10；失败不阻塞交易。
- 新建交易员默认 `dry`；API 仅监听 localhost；日志/提示词/工具入参不得出现密钥。
- 保留 25 项 `TradingRiskPolicyTests` 断言不变；新增测试不得依赖真实模型或交易所。
- 每个任务完成后必须 `dotnet build` + 对应测试通过再提交；提交只含该任务文件，不自动推送。

```csharp
using Microsoft.Agents.AI;
using Microsoft.Agents.AI.Workflows;

using Xunit;

namespace LuckyCat.Tests;

public class AgentFrameworkSpikeTests
{
    private static readonly JsonSerializerOptions Json = new(JsonSerializerDefaults.Web);

    [Fact]
    public async Task Agent_executes_tool_then_returns_typed_output()
    {
        var client = new ScriptedClient(
            Chat("call-1", "get_ping", new() { ["value"] = "hello" }),
            new ChatResponse(new ChatMessage(ChatRole.Assistant, "{\"answer\":\"hello\"}")));
        var agent = new ChatClientAgent(client, new ChatClientAgentOptions
        {
            Name = "spike",
            Instructions = "Call get_ping, then return JSON.",
            ChatOptions = new ChatOptions { Tools = [AIFunctionFactory.Create(GetPing, "get_ping", "Echo a value.")] }
        });

        var response = await agent.RunAsync<PingAnswer>("go", null, Json, null, default);

        Assert.Equal("hello", response.Result.Answer);
        Assert.Equal(2, client.Calls);
    }

    [Fact]
    public async Task Conditional_edge_routes_typed_message()
    {
        var echo = new EchoExecutor();
        var upper = new UpperExecutor();
        var lower = new LowerExecutor();
        var workflow = new WorkflowBuilder(echo)
            .AddEdge<string>(echo, upper, v => v == "hello")
            .AddEdge<string>(echo, lower, v => v != "hello")
            .WithOutputFrom(upper, lower)
            .Build();

        var run = await InProcessExecution.RunAsync<string>(workflow, "hello");
        var output = run.NewEvents.OfType<WorkflowOutputEvent>()
            .Select(e => e.Data).OfType<string>().Last();

        Assert.Equal("HELLO", output);
    }

    [Description("Echo a value.")]
    private static string GetPing([Description("Value.")] string value) => value;

    private static ChatResponse Chat(string id, string name, Dictionary<string, object?> args) =>
        new(new ChatMessage(ChatRole.Assistant,
            [new FunctionCallContent(id, name, args)]));

    public sealed record PingAnswer(string Answer);

    private sealed class ScriptedClient(params ChatResponse[] responses) : IChatClient
    {
        private int _index;
        public int Calls { get; private set; }
        public Task<ChatResponse> GetResponseAsync(IEnumerable<ChatMessage> messages,
            ChatOptions? options = null, CancellationToken cancellationToken = default)
        {
            Calls++;
            return Task.FromResult(responses[Math.Min(_index++, responses.Length - 1)]);
        }
        public IAsyncEnumerable<ChatResponseUpdate> GetStreamingResponseAsync(IEnumerable<ChatMessage> messages,
            ChatOptions? options = null, CancellationToken cancellationToken = default) => throw new NotSupportedException();
        public object? GetService(Type serviceType, object? serviceKey = null) => null;
        public void Dispose() { }
    }

    private sealed class EchoExecutor() : Executor<string, string>("echo")
    {
        public override ValueTask<string> HandleAsync(string input, IWorkflowContext context, CancellationToken ct) =>
            ValueTask.FromResult(input);
    }

    private sealed class UpperExecutor() : Executor<string, string>("upper")
    {
        public override ValueTask<string> HandleAsync(string input, IWorkflowContext context, CancellationToken ct) =>
            ValueTask.FromResult(input.ToUpperInvariant());
    }

    private sealed class LowerExecutor() : Executor<string, string>("lower")
    {
        public override ValueTask<string> HandleAsync(string input, IWorkflowContext context, CancellationToken ct) =>
            ValueTask.FromResult(input.ToLowerInvariant());
    }
}
```

`Services/Ids.cs`：

```csharp
using System.Numerics;
using System.Security.Cryptography;

namespace LuckyCat.Services;

public static class Ids
{
    private const string Alphabet = "0123456789ABCDEFGHJKMNPQRSTVWXYZ";

    public static string NewUlid()
    {
        Span<byte> bytes = stackalloc byte[16];
        var ms = (ulong)DateTimeOffset.UtcNow.ToUnixTimeMilliseconds();
        bytes[0] = (byte)(ms >> 40);
        bytes[1] = (byte)(ms >> 32);
        bytes[2] = (byte)(ms >> 24);
        bytes[3] = (byte)(ms >> 16);
        bytes[4] = (byte)(ms >> 8);
        bytes[5] = (byte)ms;
        RandomNumberGenerator.Fill(bytes[6..]);
        var value = new BigInteger(bytes, isUnsigned: true, isBigEndian: true);
        var chars = new char[26];
        for (var i = 25; i >= 0; i--)
        {
            chars[i] = Alphabet[(int)(value % 32)];
            value /= 32;
        }
        return new string(chars);
    }
}
```

```csharp
public sealed class MarketDataCache(IMarketDataReader reader)
{
    private readonly Dictionary<string, MarketSnapshot> _snapshots = new(StringComparer.Ordinal);
    private readonly Dictionary<string, MarketSnapshot?> _overviews = new(StringComparer.Ordinal);
    private readonly Dictionary<string, IReadOnlyDictionary<string, SymbolSentiment>> _sentiments = new(StringComparer.Ordinal);
    private IReadOnlyList<ExternalDataResult>? _news;
    private CoinSourceResolution? _candidates;

    public async Task<MarketSnapshot> GetSnapshotAsync(string exchange, SharedSymbol symbol, string timeframe,
        int bars, int warmupBars, CancellationToken ct)
    {
        var key = $"{exchange}|{symbol.BaseAsset}|{timeframe}|{bars}|{warmupBars}";
        if (_snapshots.TryGetValue(key, out var hit)) return hit;
        var value = await reader.GetSnapshotAsync(exchange, symbol, timeframe, bars, warmupBars, ct);
        _snapshots[key] = value;
        return value;
    }

    public async Task<MarketSnapshot?> GetBtcOverviewAsync(string exchange, CancellationToken ct)
    {
        if (_overviews.TryGetValue(exchange, out var hit)) return hit;
        var value = await reader.GetBtcOverviewAsync(exchange, ct);
        _overviews[exchange] = value;
        return value;
    }

    public async Task<IReadOnlyDictionary<string, SymbolSentiment>> GetSentimentAsync(string exchange,
        IReadOnlyList<SharedSymbol> symbols, bool oi, bool funding, CancellationToken ct)
    {
        var key = $"{exchange}|{string.Join(',', symbols.Select(s => s.BaseAsset))}|{oi}|{funding}";
        if (_sentiments.TryGetValue(key, out var hit)) return hit;
        var value = await reader.GetSentimentAsync(exchange, symbols, oi, funding, ct);
        _sentiments[key] = value;
        return value;
    }

    public async Task<IReadOnlyList<ExternalDataResult>> GetNewsAsync(IEnumerable<ExternalDataSource> sources, CancellationToken ct)
        => _news ??= await reader.GetNewsAsync(sources, ct);

    public async Task<CoinSourceResolution?> GetCandidatesAsync(StrategyConfig config, CancellationToken ct)
        => _candidates ??= await reader.GetCandidatesAsync(config, ct);
}
```

`ToolEnvelope`：

```csharp
public sealed record ToolEnvelope(bool Ok, JsonElement? Data, DateTimeOffset? AsOfUtc,
    string Source, IReadOnlyList<string> Warnings, bool Truncated, ToolError? Error)
{
    public static ToolEnvelope Success(JsonElement data, DateTimeOffset? asOf, string source,
        IReadOnlyList<string>? warnings = null)
    {
        var envelope = new ToolEnvelope(true, data, asOf, source, warnings ?? [], false, null);
        return EnforceSize(envelope);
    }

    public static ToolEnvelope Success(string text, DateTimeOffset? asOf, string source,
        IReadOnlyList<string>? warnings = null) =>
        Success(JsonSerializer.SerializeToElement(text), asOf, source, warnings);

    public static ToolEnvelope Failure(string code, string message, bool retryable = false) =>
        new(false, null, null, "incomplete", [], false, new ToolError(code, message, retryable));

    private static ToolEnvelope EnforceSize(ToolEnvelope envelope)
    {
        var json = JsonSerializer.Serialize(envelope, ApiJson.Options);
        if (json.Length <= 16 * 1024) return envelope;
        var truncated = envelope with
        {
            Data = JsonSerializer.SerializeToElement("[truncated]"),
            Truncated = true,
            Warnings = envelope.Warnings.Append("结果超过 16 KiB，已截断").ToArray()
        };
        return truncated;
    }
}
public sealed record ToolError(string Code, string Message, bool Retryable);
```

```csharp
public interface ICycleBudget { bool TryConsumeTool(string role); }

public sealed class ToolAuditor(AppDbContext db, SseEventHub hub, ICycleBudget budget,
    string? cycleId, string stageRunId, int? traderId)
{
    public async Task<ToolEnvelope> RunAsync(string tool, string role, object args,
        Func<Task<ToolEnvelope>> action, CancellationToken ct)
    {
        var started = System.Diagnostics.Stopwatch.StartNew();
        ToolEnvelope result;
        if (!budget.TryConsumeTool(role))
            result = ToolEnvelope.Failure(ToolErrors.ToolBudgetExceeded, "工具调用超预算");
        else
        {
            try { result = await action(); }
            catch (Exception ex) { result = ToolEnvelope.Failure(ToolErrors.ToolInternalError, ex.Message); }
        }
        var argsJson = JsonSerializer.Serialize(args, ApiJson.Options);
        var resultJson = JsonSerializer.Serialize(result, ApiJson.Options);
        var truncated = resultJson.Length > 16 * 1024;
        if (truncated) resultJson = resultJson[..(16 * 1024)];
        db.ToolInvocations.Add(new ToolInvocation
        {
            CycleId = cycleId, StageRunId = stageRunId, ToolName = tool,
            ArgumentsJson = argsJson, ResultJson = resultJson, Success = result.Ok,
            ErrorCode = result.Error?.Code, ElapsedMs = started.ElapsedMilliseconds,
            Truncated = truncated, CreatedAt = DateTime.UtcNow
        });
        await db.SaveChangesAsync(ct);
        if (traderId is { } tid && (ToolCatalog.IsWrite(tool) || !result.Ok))
            hub.Publish(SseChannels.Trader(tid), new SseEvent("tool", new
            {
                cycleId, stageId = stageRunId, tool, success = result.Ok,
                errorCode = result.Error?.Code, elapsedMs = started.ElapsedMilliseconds, at = DateTime.UtcNow
            }));
        return result;
    }
}
```

```csharp
public sealed class MarketTools(MarketDataCache cache, StrategyConfig config, IReadOnlySet<string> allowed)
{
    [Description("获取指定标的的 K 线紧凑表。symbol 形如 BTC/USDT；bars 10-200。")]
    public async Task<ToolEnvelope> GetKlinesAsync(
        [Description("标的，如 BTC/USDT")] string symbol,
        [Description("周期，如 1h")] string timeframe,
        [Description("K 线数量 10-200")] int bars = 60,
        [Description("是否包含进行中 K 线")] bool includeInProgress = false,
        CancellationToken ct = default)
    {
        if (!allowed.Contains(symbol)) return ToolEnvelope.Failure(ToolErrors.SymbolNotAllowed, "标的不在允许集合");
        if (bars is < 10 or > 200) return ToolEnvelope.Failure(ToolErrors.InvalidArgument, "bars 必须在 10-200");
        var shared = CoinRankingService.ParseConfiguredSymbol(symbol);
        var warmup = IndicatorCalculator.WarmupBars(config.Indicators);
        var snapshot = await cache.GetSnapshotAsync(config.CoinSource.Exchange, shared, timeframe, bars, warmup, ct);
        if (snapshot.Source != "live") return ToolEnvelope.Failure(ToolErrors.DataUnavailable, snapshot.Failure ?? "行情不可用", true);
        var barsToShow = includeInProgress ? snapshot.Klines : IndicatorCalculator.ClosedBars(snapshot.Klines, timeframe, snapshot.AsOfUtc);
        var table = string.Join('\n', barsToShow.TakeLast(bars).Select(k =>
            $"{k.OpenTime:O} | {k.Open} | {k.High} | {k.Low} | {k.Close} | {k.Volume}"));
        return ToolEnvelope.Success(table, snapshot.AsOfUtc, snapshot.Source);
    }
}
```

```csharp
    public static JsonElement ToLegacyDecision(AgentTradeProposal p)
    {
        var isLong = p.Side == TradeSide.Long;
        var action = p.Action switch
        {
            ProposalAction.Open => isLong ? "buy" : "sell",
            ProposalAction.Close => "close",
            _ => "hold"
        };
        decimal? stopPct = p.EntryPrice is > 0 && p.StopLossPrice is { } sl
            ? Math.Abs(p.EntryPrice.Value - sl) / p.EntryPrice.Value * 100m : null;
        decimal? takePct = p.EntryPrice is > 0 && p.TakeProfitPrice is { } tp
            ? Math.Abs(tp - p.EntryPrice.Value) / p.EntryPrice.Value * 100m : null;
        var obj = new Dictionary<string, object?>
        {
            ["action"] = action,
            ["symbol"] = p.Symbol,
            ["confidence"] = p.Confidence is { } c ? Math.Round(c * 100m, 0) : null,
            ["reason"] = p.Thesis,
            ["entry_price"] = p.EntryPrice,
            ["stop_loss_pct"] = stopPct,
            ["take_profit_pct"] = takePct,
            ["position_pct"] = p.PositionPct,
            ["leverage"] = p.Leverage,
            ["trigger"] = p.Action == ProposalAction.Hold ? "hold" : null
        };
        return JsonSerializer.SerializeToElement(obj);

    }
```

```csharp
            Success = result.Ok, ErrorCode = result.Error?.Code,
            ElapsedMs = started.ElapsedMilliseconds, CreatedAt = DateTime.UtcNow
        });
        await _db.SaveChangesAsync(ct);

    }
```

```csharp
private async Task<ToolEnvelope> PlaceOrderCoreAsync(
    string proposalId, string symbol, string side, string orderType,
    decimal quantity, decimal? price, decimal? leverage, decimal stopLossPrice,
    decimal? takeProfitPrice, string reason, CancellationToken ct)
{
    if (orderType is not ("market" or "limit")) return Fail(ToolErrors.InvalidArgument, "orderType 无效");
    if (orderType == "limit" && price is not > 0) return Fail(ToolErrors.InvalidArgument, "限价单必须提供价格");
    if (quantity <= 0) return Fail(ToolErrors.InvalidArgument, "数量必须大于 0");

    var proposal = await _db.TradeProposals.FindAsync([proposalId], ct);
    if (proposal is null || proposal.CycleId != _ctx.CycleId) return Fail(ToolErrors.ProposalNotFound, "提案不存在");
    if (proposal.Action != "open" || proposal.Symbol != symbol || proposal.Side != side)
        return Fail(ToolErrors.InvalidArgument, "开仓参数与提案不一致");
    if (proposal.StopLossPrice != stopLossPrice)
        return Fail(ToolErrors.InvalidArgument, "止损价必须等于提案值");
    if (proposal.TakeProfitPrice != takeProfitPrice)
        return Fail(ToolErrors.InvalidArgument, "止盈价必须等于提案值");

    var verdict = await _db.RiskVerdicts.SingleOrDefaultAsync(v => v.ProposalId == proposalId, ct);
    if (verdict is null || verdict.Decision != "approved") return Fail(ToolErrors.ProposalNotApproved, "提案未批准");
    if (verdict.ValidUntilUtc is not { } until || DateTime.UtcNow > until) return Fail(ToolErrors.ProposalExpired, "提案已过期");
    if (verdict.MaxPositionPct is not { } maxPositionPct || verdict.MaxLeverage is not { } maxLeverage)
        return Fail(ToolErrors.ProposalNotApproved, "裁决缺少批准边界");

    var account = await _accounts.GetAccountAsync(ct);
    var positions = await _accounts.GetPositionsAsync(ct);
    if (!account.Success || !positions.Success) return Fail(ToolErrors.DataUnavailable, "账户或持仓不可读", true);

    var currentLeverage = leverage ?? maxLeverage;
    if (currentLeverage > maxLeverage) return Fail(ToolErrors.LeverageExceeded, "杠杆超过批准上限");
    if (currentLeverage <= 0) return Fail(ToolErrors.InvalidArgument, "杠杆必须大于 0");

    var shared = CoinRankingService.ParseConfiguredSymbol(symbol);
    var execPrice = orderType == "limit" ? price : await _gateway.GetPriceAsync(shared, ct);
    if (execPrice is not > 0) return Fail(ToolErrors.DataUnavailable, "执行价格不可用", true);

    if (orderType == "limit")
    {
        var limitPrice = price!.Value;
        if (verdict.EntryZoneMin is not { } min || verdict.EntryZoneMax is not { } max ||
            limitPrice < min || limitPrice > max)
            return Fail(ToolErrors.PriceOutOfBand, "限价超出批准价格带");
    }
    else
    {
        if (!(verdict.AllowMarket ?? false)) return Fail(ToolErrors.InvalidArgument, "裁决不允许市价");
        if (proposal.EntryPrice is > 0 && Math.Abs(execPrice.Value / proposal.EntryPrice.Value - 1m) * 100m > 0.5m)
            return Fail(ToolErrors.PriceOutOfBand, "市价偏离提案价超过 0.5%");
    }

    var submittedMargin = quantity * execPrice.Value / currentLeverage;
    var approvedMargin = account.UsdtEquity * maxPositionPct / 100m;
    if (submittedMargin > approvedMargin) return Fail(ToolErrors.QuantityExceeded, "保证金超过批准上限");

    var spec = await _gateway.GetFuturesSpecAsync(shared, ct);
    var exchangeMaxLeverage = side == "long" ? spec?.MaxLongLeverage : spec?.MaxShortLeverage;
    var context = new OpenRiskContext(account.UsdtEquity, account.UsdtAvailable,
        TraderRunnerService.UsedMargin(account, positions.Positions), positions.Positions.Count,
        positions.Positions.Any(p => TradingRiskPolicy.BaseAsset(p.Symbol) == TradingRiskPolicy.BaseAsset(symbol)),
        execPrice.Value, exchangeMaxLeverage ?? 1m, spec?.QuantityStep ?? 0m,
        spec?.MinTradeQuantity ?? 0m, spec?.MinNotionalValue ?? 0m, await _accounts.GetDisciplineAsync(ct));
    if (TradingRiskPolicy.ValidateOpen(ProposalRiskAdapter.ToLegacyDecision(proposal), _config.RiskControl,
        context, out _) is { } riskError)
        return Fail(ToolErrors.RiskPolicyViolation, riskError);

    var fresh = await _market.GetSnapshotAsync(_exchange, shared, _ctx.Timeframe, 2, 0, ct);
    if (fresh.Source != "live" || fresh.AsOfUtc is not { } asOf || DateTime.UtcNow - asOf > TimeSpan.FromMinutes(3))
        return Fail(ToolErrors.StaleMarketData, "行情缺失或超过 3 分钟");

    var attempt = _attempt++;
    var clientOrderId = ClientOrderId(_ctx.CycleId, proposalId, attempt);
    if (await _db.TraderOrders.AnyAsync(o => o.CycleId == _ctx.CycleId && o.ClientOrderId == clientOrderId, ct))
        return Fail(ToolErrors.DuplicateOrder, "重复订单");

    if (_ctx.Mode == "dry")
    {
        var simulated = NewOrder(clientOrderId, symbol, side, quantity, execPrice.Value, currentLeverage,
            "filled", true, quantity, execPrice, proposalId, verdict.Id);
        _db.TraderOrders.Add(simulated);
        await _db.SaveChangesAsync(ct);
        hub.Publish(SseChannels.Trader(_ctx.Trader.Id), new SseEvent("order", simulated));
        return ToolEnvelope.Success(JsonSerializer.SerializeToElement(new { orderId = simulated.Id, clientOrderId, status = "filled", simulated = true }), DateTimeOffset.UtcNow, "live");
    }

    var placed = await _gateway.PlaceAsync(shared, side == "long", quantity, stopLossPrice,
        takeProfitPrice ?? 0m, currentLeverage, ct);
    var status = !placed.Ok ? "failed" : placed.FilledQuantity is null ? "submitted" :
        placed.FilledQuantity >= quantity ? "filled" : "partial";
    var row = NewOrder(clientOrderId, symbol, side, quantity, execPrice.Value, currentLeverage,
        status, false, placed.FilledQuantity, placed.AveragePrice, proposalId, verdict.Id);
    row.ExchangeOrderId = placed.ExchangeOrderId;
    row.Error = placed.Error;
    _db.TraderOrders.Add(row);
    await _db.SaveChangesAsync(ct);
    hub.Publish(SseChannels.Trader(_ctx.Trader.Id), new SseEvent("order", row));
    return placed.Ok
        ? ToolEnvelope.Success(JsonSerializer.SerializeToElement(new { orderId = row.Id, clientOrderId, status = row.Status }), DateTimeOffset.UtcNow, "live")
        : ToolEnvelope.Failure(ToolErrors.ExchangeError, placed.Error ?? "下单失败");
}

private TraderOrder NewOrder(string clientOrderId, string symbol, string side, decimal quantity,
    decimal price, decimal leverage, string status, bool simulated, decimal? filled, decimal? average,
    string proposalId, string verdictId) => new()
{
    CycleId = _ctx.CycleId, TraderId = _ctx.Trader.Id, ExchangeAccountId = _ctx.Account.Id,
    ProposalId = proposalId, VerdictId = verdictId, ClientOrderId = clientOrderId,
    Action = "open", Side = side, Symbol = symbol, Quantity = quantity, Price = price,
    FilledQuantity = filled, AveragePrice = average, Leverage = leverage, Status = status,
    Simulated = simulated, Success = status != "failed", At = DateTime.UtcNow
};

private static string ClientOrderId(string cycleId, string orderKey, int attempt)
{
    var hash = Convert.ToHexString(SHA256.HashData(Encoding.UTF8.GetBytes(orderKey)))
        .ToLowerInvariant()[..8];
    return $"lc-{cycleId[^12..]}-{hash}-{attempt}";
}
```

```csharp
private async Task<ToolEnvelope> ClosePositionCoreAsync(string? proposalId, string symbol, decimal? quantity,
    string orderType, decimal? price, string reason, CancellationToken ct)
{
    if (orderType is not ("market" or "limit")) return Fail(ToolErrors.InvalidArgument, "orderType 无效");
    if (orderType == "limit" && price is not > 0) return Fail(ToolErrors.InvalidArgument, "限价单必须提供价格");
    var shared = CoinRankingService.ParseConfiguredSymbol(symbol);
    var positions = await _accounts.GetPositionsAsync(ct);
    if (!positions.Success) return Fail(ToolErrors.DataUnavailable, "持仓不可读", true);
    var position = positions.Positions.FirstOrDefault(p =>
        TradingRiskPolicy.BaseAsset(p.Symbol) == TradingRiskPolicy.BaseAsset(symbol));
    if (position is null) return Fail(ToolErrors.PositionNotFound, "无该标的持仓");
    var qty = quantity ?? position.Quantity;
    if (qty <= 0 || qty > position.Quantity) return Fail(ToolErrors.QuantityExceeded, "平仓数量超过持仓");
    if (proposalId is not null)
    {
        var closeProposal = await _db.TradeProposals.FindAsync([proposalId], ct);
        if (closeProposal is null || closeProposal.CycleId != _ctx.CycleId || closeProposal.Action != "close")
            return Fail(ToolErrors.InvalidArgument, "平仓提案不存在或不属于本周期");
    }
    var latest = await _gateway.GetPriceAsync(shared, ct);
    if (latest is not > 0) return Fail(ToolErrors.DataUnavailable, "最新价不可用", true);
    if (orderType == "limit" && Math.Abs(price!.Value / latest.Value - 1m) * 100m > 2m)
        return Fail(ToolErrors.PriceOutOfBand, "限价偏离最新价超过 2%");
    var execPrice = orderType == "limit" ? price!.Value : latest.Value;
    var fresh = await _market.GetSnapshotAsync(_exchange, shared, _ctx.Timeframe, 2, 0, ct);
    if (fresh.Source != "live" || fresh.AsOfUtc is not { } asOf || DateTime.UtcNow - asOf > TimeSpan.FromMinutes(3))
        return Fail(ToolErrors.StaleMarketData, "行情缺失或超过 3 分钟");
    var side = position.Side == SharedPositionSide.Long ? "long" : "short";
    var clientOrderId = ClientOrderId(_ctx.CycleId, proposalId ?? $"close-{symbol}", _attempt++);
    if (await _db.TraderOrders.AnyAsync(o => o.CycleId == _ctx.CycleId && o.ClientOrderId == clientOrderId, ct))
        return Fail(ToolErrors.DuplicateOrder, "重复订单");

    var row = new TraderOrder
    {
        CycleId = _ctx.CycleId, TraderId = _ctx.Trader.Id, ExchangeAccountId = _ctx.Account.Id,
        ProposalId = proposalId, VerdictId = null, ClientOrderId = clientOrderId,
        Action = "close", Side = side, Symbol = symbol, Quantity = qty, Price = execPrice,
        Leverage = position.Leverage, Simulated = _ctx.Mode == "dry",
        Status = _ctx.Mode == "dry" ? "filled" : "submitted",
        FilledQuantity = _ctx.Mode == "dry" ? qty : null,
        AveragePrice = _ctx.Mode == "dry" ? execPrice : null,
        Success = _ctx.Mode == "dry", At = DateTime.UtcNow
    };
    if (_ctx.Mode != "dry")
    {
        var closed = await _gateway.CloseAsync(shared, qty, position.Side == SharedPositionSide.Long, ct);
        row.Status = closed.Ok ? "filled" : "failed";
        row.FilledQuantity = closed.Quantity;
        row.AveragePrice = closed.Price;
        row.Success = closed.Ok;
        row.Error = closed.Error;
    }
    _db.TraderOrders.Add(row);
    await _db.SaveChangesAsync(ct);
    hub.Publish(SseChannels.Trader(_ctx.Trader.Id), new SseEvent("order", row));
    return row.Status == "failed"
        ? ToolEnvelope.Failure(ToolErrors.ExchangeError, row.Error ?? "平仓失败")
        : ToolEnvelope.Success(JsonSerializer.SerializeToElement(new { orderId = row.Id, status = row.Status }), DateTimeOffset.UtcNow, "live");
}
```

```csharp
public async Task RunAsync(Trader trader, CancellationToken ct)
{
    var cycleId = Ids.NewUlid();
    var config = await LoadConfigAsync(trader, ct);
    var provider = await _db.Providers.FindAsync([trader.ProviderId], ct)
        ?? throw new InvalidOperationException("模型提供商不存在");
    var account = await _db.ExchangeAccounts.FindAsync([trader.ExchangeAccountId], ct)
        ?? throw new InvalidOperationException("交易所账户不存在");
    using var scope = _scopeFactory.CreateScope();
    var recorder = scope.ServiceProvider.GetRequiredService<CycleRecorder>();
    var cycle = await recorder.StartCycleAsync(cycleId, trader, config, "schedule", ct);
    var marketCache = new MarketDataCache(scope.ServiceProvider.GetRequiredService<IMarketDataReader>());
    var budget = new CycleBudget(config.AgentBudget);
    var ctx = new TradingCycleContext(cycleId, trader, config, provider, account,
        trader.ExecutionMode, "schedule", config.CoinSource.Exchange, config.Indicators.PrimaryTimeframe,
        marketCache, scope.ServiceProvider.GetRequiredService<IAccountReader>(), budget, recorder);
    try
    {
        using var timeout = CancellationTokenSource.CreateLinkedTokenSource(ct);
        timeout.CancelAfter(TimeSpan.FromSeconds(config.AgentBudget.CycleTimeoutSeconds));
        var workflow = BuildWorkflow(ctx);
        await using var run = await InProcessExecution.RunStreamingAsync<CycleInput>(
            workflow, new CycleInput(cycleId), (string?)null, timeout.Token);
        await foreach (var evt in run.WatchStreamAsync())
        {
            await CycleEvents.HandleAsync(evt, ctx, timeout.Token);
        }
        // 成功周期由 Finalizer 完成；这里不重复 CompleteCycleAsync。
    }
    catch (OperationCanceledException) when (!ct.IsCancellationRequested)
    {
        await recorder.CompleteCycleAsync(ctx, "failed", "cycle_timeout", "周期超时", CancellationToken.None);
    }
    catch (Exception ex)
    {
        await recorder.CompleteCycleAsync(ctx, "failed", "unhandled", ex.Message, CancellationToken.None);
    }
}
```

- 交易员级 `ConcurrentDictionary<int, SemaphoreSlim>` 确保同一交易员只有一个周期；账户写锁在 `ExecutionTools` 内。
- `BuildWorkflow(ctx)` 在周期 scope 内解析 `ChatClientFactory` 创建 `IChatClient`，构造 `ToolRegistry` 与四个执行器；client 生命周期绑定到周期，周期结束 dispose。
- `RecoverAsync`：把所有 `running` 周期改为 `aborted` + `process_restart`；启动时调用。

```ts
async function request<T>(path: string, init?: RequestInit): Promise<T> {
  const response = await fetch(path, {
    ...init,
    headers: { 'Content-Type': 'application/json', ...(init?.headers ?? {}) }
  });

  if (!body.success) throw new Error(body.error?.message ?? '请求失败');

}

export function openTraderStream(traderId: number, onEvent: (event: CycleEvent) => void): () => void {
```
