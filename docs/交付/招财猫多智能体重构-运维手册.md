# 招财猫多智能体重构 — 运维手册

> 适用版本：`refactor/maf-multi-agent`（2026-10-26）｜面向：本机单进程部署
> 接口与错误码以 [LC-STD-03](../standards/03-数据模型与接口契约规范.md) 为准；本文只讲「怎么跑、怎么看、出问题怎么办」。

## 一、进程、端口与日志

| 项 | 值 |
| --- | --- |
| 后端 | `dotnet run --project LuckyCat.csproj --no-launch-profile`，固定监听 `http://localhost:5210` |
| 前端（开发） | `cd web && bun run dev`，Vite 默认 5173，`/api` 代理到 5210 |
| 前端（生产） | `cd web && bun run build` → `web/dist/`，静态托管 + `/api` 反代到 5210 |
| 数据库 | 进程**当前目录**下 `luckycat.db`（SQLite）；启动路径不同会连到不同的库 |
| 日志 | 标准输出（`Console`）：周期/阶段/工具/SSE/HTTP 重试；`OTEL_CONSOLE=1` 追加 OTel 控制台导出 |
| 健康检查 | `curl -s http://localhost:5210/api/health` → `success:true`、`database:true` |

后台常驻运行（脱离工具进程组，避免被回收）：

```bash
nohup dotnet run --project /path/to/LuckyCat.csproj --no-launch-profile > /tmp/luckycat-api.log 2>&1 &
nohup bun run dev > /tmp/luckycat-web.log 2>&1 &        # 在 web/ 目录
```

停止后端：`lsof -tiTCP:5210 -sTCP:LISTEN | xargs kill`。

## 二、运行期时间口径

| 机制 | 口径 |
| --- | --- |
| 交易周期 | 每个交易员同一时刻只有一个周期；启动后立刻跑首轮，之后按 `ScanIntervalMinutes`（3–60，默认 3）循环 |
| 周期/阶段超时 | 周期 300s；分析师/交易员 90s、风控/执行 45s（可在策略 `agentBudget` 调整） |
| 工具预算 | 每阶段 20/10/4/6，单周期 45（超出返回 `tool_budget_exceeded`，不抛异常） |
| 复盘 | 每日**服务器本地时区** `review.localTime`（默认 00:10）；窗口为「上次成功复盘之后，最多 30 天」；120s / 10 次工具 |
| 明细清理 | 每日**本地 03:30** 清理 90 天前的 `AgentStageRun` / `ToolInvocation`（`Services/DataRetentionService.cs`）；订单、提案、裁决、经验永久保留 |
| 时间存储 | 数据库与接口统一 UTC（`Z`）；前端按浏览器本地时区展示 |

## 三、日常巡检

1. `/api/health` 为 `success:true` 且 `database:true`。
2. 交易员状态：看板「系统状态」ONLINE；看板与 SSE `state` 的 `lastCycleStatus` 只会是 `running/completed/failed/skipped/aborted` 或 null（写入侧保证；`GET /api/traders` 的原样字段未做白名单过滤）。
3. 周期历史页：最近几个周期应交替出现 `completed`，失败要看 `errorCode`（`risk_stage_failed` / `stage_failed` / `cycle_timeout` / `token_budget_exceeded` 等，见 LC-STD-03 §6）。
4. 复盘经验页：每日一条复盘记录；连续 `skipped` 说明窗口内没有平仓样本（正常）。
5. `get_news` 若含「源 X 缺席」警告：单源网络问题，不影响周期；连续缺席再看网络。

## 四、常见故障处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 启动/试运行返回 422 `provider_capability_missing` | 模型未通过工具调用验证 | 在「模型」卡片点「验证」，通过后再启动 |
| 账户区显示「账户数据读取失败」并带 `-2014` / `Invalid key` | 交易所 Key 无效、权限不足或需 IP 白名单 | 核对 Key/权限；Gate 不需要 IP 白名单，Binance 需要 |
| 409 `cycle_in_progress` | 该交易员已有周期在跑 | 等当前周期结束；手动平仓同理 |
| 复盘 409 `review_in_progress` | 60 秒内重复触发，或已有复盘在跑 | 稍后再试 |
| 复盘 422 `review_no_data` | 窗口内没有已平仓交易且没有周期 | 属正常「跳过」，不是故障 |
| 周期长时间 `running` | 进程异常退出/被杀 | 重启进程：启动恢复会把遗留 `running` 标为 `aborted` + `process_restart`，并恢复 `IsRunning` 交易员调度 |
| 周期 `failed` + `cycle_timeout` | 超过 300s | 看阶段耗时；必要时提高预算或减少候选币种 |
| 周期 `failed` + `risk_stage_failed` | 风控阶段异常/超时 | fail-closed，不下单；查该周期阶段记录 |
| 阶段日志里大量 `tool_budget_exceeded` | 工具预算对当前候选数不够 | 在工作室「预算与复盘」调高对应阶段上限后保存 |
| 手动平仓返回 `order=null` + `execution_errors` | 写工具被硬闸拒绝（无持仓、限价缺价、数量超限等） | 按响应里的 `error` 修正；不要重复盲试 |
| 「最近决策」区块消失 | 旧决策表在新链路不再写入，空列表时整块隐藏 | 预期行为；历史数据看「周期历史」 |
| 前端打开后接口全 404/连不上 | 后端未启动或未走 Vite 代理 | 先起后端 5210，再 `bun run dev`；生产环境确认 `/api` 反代 |
| 新闻某源长期缺席 | 上游不可达/改版（外部源无 SLA） | 隔轮重试；单发失败不等于源故障；持续缺席再看 LC-STD-06 的端点 |

## 五、数据备份与保留

```bash
# 备份（建议停服务后复制，或使用 sqlite3 在线备份）
cp luckycat.db luckycat.db.bak-$(date +%Y%m%d%H%M%S)
sqlite3 luckycat.db ".backup 'luckycat.db.bak'"
```

- 升级存量库：执行 `docs/sql/2026-10-26-多智能体新表.sql`（详见交付说明 §3.2）。脚本第 2 节是一次性 `ALTER TABLE`，重复执行会报列已存在/无此列。
- 旧表 `DecisionRecords` 等不再读写，默认不删；需要瘦身可手工清理（不在本系统职责内）。
- 阶段与工具明细 90 天后自动清理；`TraderLesson.stageRunId` 是历史引用，90 天后可能无法展开到阶段明细，经验正文照常保留。

## 六、安全约束（务必遵守）

1. **无鉴权**：应用只监听 `localhost`，不要绑定到 `0.0.0.0` 或做公网反代；确需远程访问应先加认证与 TLS。
2. **密钥只在数据库**：模型/交易所凭据保存于 `Providers` / `ExchangeAccounts`，读取接口只回掩码；不要把 `luckycat.db` 提交进版本库（已在 `.gitignore`）。
3. **日志已脱敏**：异常信息经 `LogRedaction.Scrub` 处理后才进日志；工具/周期错误对外只给稳定错误码 + 固定中文摘要。
4. **非幂等调用不重试**：全局 HTTP 弹性管道只作用于 `IHttpClientFactory`（新闻/情绪等只读请求）；交易所下单/平仓/撤单客户端自行构造，不经该管道，未知结果只落占位行并提示人工核对。
5. **写操作唯一入口**：模型只能经 `place_order` / `close_position` / `cancel_order` 三个工具发起交易，且都经过 12 步硬闸；系统不提供提现/划转/密钥类工具。
